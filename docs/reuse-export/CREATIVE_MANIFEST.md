## 2. Context packs (`lib/creative-engine/brand-context/`)

**Versions** (`types.ts`):
- `COMPILER_VERSION = 4` (l.175).
- `RENDERER_VERSIONS = { copy: 3, image: 5, judge: 4 }` (l.196). CLAUDE.md still shows `{2,3,2}` and `{3,4,3}` in older sections, and the in-file `COMPILER_VERSION` comment stops at v3.

**Slot budgets:** facts 3 (plus 1 lesson), voice 2, rules all, assets 4, persona exactly 1.

**What the compiler pulls in:** the brand's live `brand_facts` (every section **except** `performance_prior`, see §11.3), the profile `brand_kit` (logo, colours, fonts, product images) and the org guidelines.

They become typed rows (`fact | voice | rule | asset | persona`), with priority = status base (confirmed 200, candidate 100) + round(confidence × 100), and tag filters `channels/products/audiences/stages/themes`. Persona citations become `audiences`/`stages` tags on the facts they cite, and `themes` come from `deriveFactThemes` (keyword vocabulary in `themes.ts`).

**Selection, inside `compile`:**
- **Persona:** only via `personaRef`, never by tag.
- **Facts:** tag-filtered, then sorted by (exact `angleTheme` match desc, priority desc, rowId asc). A pinned `keyMessageRef` always goes first.
- **Lessons:** only via `lessonRefs`.
- **Output:** the pack echoes the spec, then `rowRefs` (sorted), then the slots.

**Hashes:**
- **Pack fingerprint:** `sha256(canonicalJson(pack))` (`fingerprint.ts:19`), 64 hex characters. It covers the versions, `brandProfileId`, the spec echo, the row refs and the full slot contents, and is the primary key of `brand_context_packs`.
- **Row content hash:** `sha256(canonicalJson({content, priority, tagFilters}))`. `sourceRef` and `rowId` are excluded. It is the ingest change detector: a changed hash creates a new row version, and rows are never deleted.

**What a pack looks like:** see `fixtures/creative-brief.json` → `briefs[i].pack` (shape: `contracts-creative.ts` `BrandContextPack`).

**Fingerprint re-minting:**
- **What it is:** fingerprints are content hashes, so any change to compiler output or template text for the same inputs changes every fingerprint.
- **What Adcero does when that happens:** it bumps `COMPILER_VERSION` or `RENDERER_VERSIONS`, re-records the golden literals in `tests/unit/creative-engine/brand-context/compile.test.ts` and the renderer snapshots by hand, and accepts that in-flight briefs whose stored packs carry old renderer versions fail with **409 `RENDERER_VERSION_MISMATCH`** (`COMPILER_VERSION` is not checked at runtime).
- **Smallest stub for you:** don't persist packs. Recompile per run (it is pure and fast), so there is nothing stale to mismatch. If you do store packs, re-mint on any renderer edit.

## 4. Strategy (`generation/strategy.ts` and friends)

**Inputs and outputs:** `selectStrategy(input: SelectStrategyInput): SelectedStrategy` (`strategy.ts:474`). Types are verbatim in `contracts-creative.ts` §4.

**What it does:**
- **Angle precedence:** explicit → experiment `angleKey` → top-ranked angle signal → `goal_blueprint`.
- **Ranking:** signals are ranked Σ(source weight × weight), with source weights own_genome 3, own_belief 2.5, own_label 2, market_prior 1.5, industry/pooled 1.
- **Groups:** `rankedProducibleHooks` (l.335) and `rankedProducibleFormats` (l.359) feed `buildStrategyGroups(signals, hooks, formats, maxGroups)` (l.382). That pairs `hooks[i]` with `formats[i % n]` via `buildGroup` (l.305, **not exported**) and attaches per-group execution cues. The group key is `${hook}__${format}`, with at most 4 groups.

**How it reads priors from `performance_memory`:** the briefs route calls `fetchPerformancePriors` (`loop/service.ts:1716`). That runs `readPerformanceMemory({source:'genome'})` (`loop/service.ts:1570`) → `derivePerformancePriors` (`loop/priors.ts`): top angle (prose), persona, hook and style by **ROAS**, after spend ≥ 20 and impressions ≥ 500. Then `signalsFromPerformancePriors` turns the top angle and hook into signals. The sampler reads the same table's `scores.beliefs` on `angle_universal` / `hook_archetype` / `format`.

**What a bandit replaces:**
- **Selection logic:** the three per-dimension stages inside `selectSampledStrategy` (`sampled-strategy.ts:194-406`: angle stage ~256-285, hook ~287-314, format ~316-347).
- **Call site:** `briefs/route.ts:523-593`, the sampler block.
- **What survives unchanged:** everything downstream (composeBrief, canonicalize, angleTheme, compile, copy, gates).

**The smallest interface change**, a rewrite of ~30 LOC promoted from `arena/driver/operator.ts:73-100`. This exact function ran in the fixture generator:

```ts
// generation/strategy-from-arms.ts (new, pure)
import { ANGLES } from '@/services/ad-library/label-taxonomy';
import { buildStrategyGroups, deterministicAngleDirective, producibleHookAllowlist,
         rankedProducibleFormats, type SelectStrategyInput, type SelectedStrategy } from './strategy';
export interface ChosenArm { segment: string; angleUniversal: string; hookArchetype: string; format?: string }
export function strategyFromArms(arms: ChosenArm[], input: SelectStrategyInput): SelectedStrategy {
  const angles = [...new Set(arms.map((a) => a.angleUniversal))];
  if (angles.length !== 1) throw new Error('one brief carries one angle: group arms by (segment, angle) first');
  const token = angles[0];
  if (token === 'other' || !(ANGLES as readonly string[]).includes(token)) throw new Error(`angle "${token}" is not pickable`);
  const allowed = new Set<string>(producibleHookAllowlist(input.packHints));
  const hooks = arms.map((a) => a.hookArchetype);
  for (const h of hooks) if (!allowed.has(h)) throw new Error(`hook "${h}" is not producible under these pack hints`);
  if (new Set(hooks).size !== hooks.length) throw new Error('duplicate hook in one brief'); // group key is hook__format
  const fill = rankedProducibleFormats(input.signals, hooks.length);
  const formats = arms.map((a, i) => a.format ?? fill[i % fill.length]);
  return { angleKey: token, angleDirective: deterministicAngleDirective(token),
           groups: buildStrategyGroups(input.signals, hooks as never, formats as never, hooks.length),
           alternates: [], evidence: input.signals.slice(0, 12), fallbackTier: 'evidence' };
}
```

Pass the real market `signals` if you have them, so per-group `executionDirective` / `executionNotes` survive; the arena passes `[]`. For N creatives over k arms in one brief, call `generateBrandCopy` once per group and repeat to N/k (Adcero round-robins `index % groups.length`).


## 5. Copy generation (`generation/brand-copy.ts`)

**Call shape:**
- **Model:** `CREATIVE_BRAND_COPY_MODEL` (default **`gpt-4o`**, `lib/llm/model-roles.ts:101`) through `getLLMProvider(CREATIVE_BRAND_COPY_PROVIDER || 'openai').complete`.
- **Request** (captured verbatim in the fixture's `copyRequests`): Chat Completions with `temperature 0.6`, `max_tokens 512`, `response_format: {type:'json_object'}`.
- **One copy set per call, one call per strategy group,** and at most one feedback retry. Groups are capped at `min(groups ≤ 4, candidateCount)`.

**Prompt, part 1 — `renderCopyPrompt(pack)` (`renderers/copy.ts`):**
- The system prompt is a senior DR copywriter brief: ground every claim only in the facts, never invent numbers, express the angle and don't quote it.
- The user text sections, in order: `## Brand facts` → `## Brand voice` → `## Persona` → `## Audience override` → `## Task` → `## Rules (non-negotiable)`.
  - `## Brand facts` takes the 3 slots; the KEY MESSAGE goes first.
  - `## Persona` holds pains, desires, objections and verbatims.
  - `## Task` holds platform and goal, the internal angle ("express it, never quote it") and `BANNED_AD_SPEAK`.

**Prompt, part 2 — appended by `brand-copy.ts`, outside the pack contract:**
- `## Strategy for this variant`: `Hook archetype to execute: <hookDirective>` and `Image shot direction: <sceneDirective>`.
- `BRAND_COPY_FORMAT_INSTRUCTION`.
- On retry, `## Previous attempt rejected\n<reason>`.

**Output:** JSON `{headline ≤60, primaryText ≤500, cta ∈ PLATFORM_CTA_LABELS, visualConcept?}`. There is no zod schema; code guards run in this order:
1. completeness
2. truncation
3. `coerceCtaLabel`
4. `findUngroundedNumerals(copy, copyPrompt.user)`
5. `findBannedPhrases`

A content failure gets one retry with the feedback; a second failure makes the whole set fall back to the brief's own copy (`source: 'brief_fallback'`). The function never throws.

`sanitizeVisualConcept` **drops** the concept if it contains any digit or a double quote, and caps it at 300 characters. The fixture shows both behaviours:
- group 1's first attempt cited "15g" and was rejected with `Copy contains number(s) not present in any brand fact: 15`, then retried;
- group 3's visual concept contained "7 am" and was dropped, so its visual line fell back to the variation text.

**How voice and facts are injected:** only through pack slots, plus the strategy block. Brief `compliance` (prohibited claims, disclaimers) is **not** in the copy prompt unless it exists as pack rules; it is enforced afterwards by the gates.

**Competitor ads as input:**
- **Not today.** The only competitor-derived signals reaching copy are:
  - the templated angle directive (chosen by `market_prior` share);
  - the fixed `HOOK_PRODUCIBILITY[hook].hookDirective`;
  - the fixed format `sceneDirective`;
  - **unintentionally**, `market_prior` fact statements ("Winning competitor ads in this set use … in 7 of 12 …"), which can win a brand-fact slot (§11.3).
- **Image prompt only:** sanitized `executionNotes` from winning competitor ads reach only the image variation text, never copy.
- **Never:** competitor ad body text never reaches either.
- **Where it would go:** add an optional `competitorReference?: {angle, hook, adaptedNotes}` to `GenerateBrandCopyInput.strategy` and render it in `buildStrategyBlock`. That stays outside the pack contract, so there's no renderer bump, and numbers in it are *not* grounding (grounding is `copyPrompt.user` only), which correctly blocks copying a competitor's figures.
  - **Threading:** `StrategyGroup` → add the field to the `extractStrategyStamp` whitelist (`stamp.ts`) if you persist briefs → the processor's/orchestrator's `generateBrandCopy` call.
  - **Scrubbing:** strip competitor names with `sanitizeExecutionNotes` (`lib/brand-object/execution-notes.ts`, already in `files.txt`).

## 6. Judge gate, gates, ranking, producibility

### 6.1 Judge gate (`generation/judge-gate.ts`, `JUDGE_GATE_VERSION='judge-gate-v3'`)
- **Model:** `CREATIVE_JUDGE_GATE_MODEL` (default gpt-4o) through `openAIChatCompletion` with strict `json_schema` (`{items:[{id, passed, note|null}]}`), temperature 0.
- **Input:** image 1 is the creative at `detail:'low'`; image 2 is the pack product image, if any.
- **Modes:** `CREATIVE_JUDGE_GATE_MODE` = `off | shadow (default, unknown → shadow) | enforce_structural | enforce`.
- **Checklist** (`renderJudgeChecklist`):
  - one item per pack rule (`<rowId>@vN`, advisory);
  - `structural_no_added_text@r2` (enforced);
  - `structural_product_fidelity@r2` (enforced; only with a product image);
  - `structural_scene_relevance@r3` (advisory).
- **What each mode does:**
  - shadow: the gate is `unverified` and never blocks;
  - enforce_structural: only enforced items block;
  - enforce: every item blocks;
  - any judge failure → `unverified`.
- **Cost:** 3¢ per judged candidate, **charged in shadow too**.
- **Text-only:** the judge needs an image, so turn it off (or omit `policyCheck`), and the `policy` gate reports `unverified`. A text-only rule judge (rule items only, no image parts) would be a ~40 LOC rewrite over `buildJudgeGateRequestBody`. It does not exist.

### 6.2 Deterministic gates (`generation/gates.ts`, `runGates`)

| gate | fails when | repairable |
|---|---|---|
| `prohibited_claims` | Case-insensitive substring of a brief prohibited claim in copy (or in-image text) | yes |
| `disclaimer` | A required disclaimer is not present verbatim | yes |
| `lexicon` | A brand avoid-word matches on a word boundary | yes |
| `copy_grounding` | Brand mode only. Reports `unverified`, never `fail` (v1) | — |
| `genome_complete` | Required genome field missing | no (hard kill) |
| `product_fidelity` | Never fails (`pass` with a product reference, else `unverified`) | — |
| `policy` | The injected judge, or `unverified` if none | yes when enforcing |

**Repair** (`pipeline-repair.ts`, image path only): edits or regenerates the image and strips claims and avoid-words from `copyText`. **Defect §11.1.** In text mode there's no image to repair; treat a `fail` as `gated_out` or regenerate the copy.

### 6.3 Ranking (`generation/ranking.ts`, `rankCandidates(candidates, brief) → Map<id, CandidateRank>`)
- **With any `imageRef`:** one batched vision call (`llm-judge-v2-multimodal`, `CREATIVE_RANK_JUDGE_VISION_MODEL` default gpt-4o-mini).
- **Text only:** `llm-judge-v1` via `getLLMProvider().complete`, `CREATIVE_RANK_JUDGE_MODEL` default **gpt-5.4-mini**, temperature 0, `maxTokens` 2048. **Probably always falls back (§11.2).** Set `CREATIVE_RANK_JUDGE_MODEL=gpt-4o-mini`.
- **Fallback (one level):** `heuristic-v1` = `clamp(10 + 60·(brief keywords found in copy / brief keywords) + 20·(a brief hook string found verbatim) − 5·#unverified gates)`.
  - **For strategy-driven briefs this is near-meaningless.** The keywords come from the templated angle directive ("proven", "winning", "market"), and the hooks are directive sentences that good copy never repeats. The fixture's four creatives score 15 / 8 / 8 / 8.
  - Let your simulator be the ranker.

### 6.4 Producibility (`generation/producibility.ts`, a strategy-time filter, not a gate)
- **Formats:**
  - producible: `product_only_static, lifestyle_static, studio`;
  - adaptable: `ugc, unboxing`;
  - not producible: `founder_talking, product_demo, tutorial_howto` (video), `text_overlay_static, meme, testimonial_review, social_screenshot, us_vs_them, before_after, press_advertorial` (on-image text, banned by the clean-image doctrine), `carousel_listicle, carousel_product_set`, `other`.
- **Hooks:**
  - producible: `problem_callout, bold_claim, question, curiosity, pov_relatable`;
  - adaptable: `statistic` (numeric fact), `social_proof` (proof_point/voc_praise fact), `testimonial` (persona verbatims), `offer_led` (offer wording), `story_narrative`;
  - not producible: `demo, comparison, other`.
- **For a text-only simulation:** the format exclusions are image constraints. If you want text arms for `us_vs_them`, `comparison` or `testimonial_review`, edit those two tables (copy + edit) and rerun your arm-space build. Pin the change in your tests, because Adcero's arena structural test keys on these tables.

## 8. The loop: where simulation rewards go (`loop/`)

**Two channels feed strategy today.**

| | Greedy priors | Thompson sampler |
|---|---|---|
| Path | `fetchPerformancePriors` | `readPerformanceMemory` → `armsFromBeliefs` |
| Rows read | genome rows, dims `angle` (prose), `persona`, `hook_archetype`, `style` | `angle_universal`, `hook_archetype`, `format` |
| Needs | spend ≥ 20, impressions ≥ 500, purchase value > 0 | `scores.beliefs` |
| Ranks by | ROAS | sampled beliefs |
| Default state | live | beliefs and sampler both **off** |

**A clicks-only simulation never moves the greedy channel unless it also invents spend and value.**

**The recommended seam is the pure rollup core**, which avoids `loop/service.ts` (1,800 LOC, whose imports drag in publish/fence/Meta/Google Ads, ~175 files) and every rollout gate. The fixture generator ran exactly this code:

```ts
import { rollupPairs } from '@/lib/creative-engine/loop/rollup';
import { buildCellBeliefs, deriveBeliefPriors } from '@/lib/creative-engine/loop/posterior';
import { armsFromBeliefs, thompsonPick, widestCurvePick, makeRng } from '@/lib/creative-engine/loop/sampler';
// 1. sim → one DailyMetricInput per creative per sim-day (spend/purchaseValue 0 unless you also want greedy priors)
const items = creatives.map((c) => ({ adId: c.id, itemId: c.id, platform: 'sim', pairs: [['angle_hook', `${c.angle}|${c.hook}`]] }));
const rows = rewards.map((r) => ({ adId: r.creativeId, date: r.day, spend: 0, impressions: r.impressions, clicks: r.clicks,
  purchases: r.conversions, purchaseValue: 0, enhancedPurchases: null, enhancedPurchaseValue: null }));
// 2. the real decayed rollup (14-day half-life, fatigue, contamination scrub)
const rollups = rollupPairs(items as never, rows, 'genome', { asOf });
// 3. beliefs (vague Beta(1,1) priors; pass pooled cells to deriveBeliefPriors for informed priors)
const table = deriveBeliefPriors([]);
const beliefRows = rollups.map((r) => ({ dimension: r.dimension, dimensionValue: r.dimensionValue, beliefs: buildCellBeliefs(r, table),
  decayedImpressions: r.decayedImpressions, decayedClicks: r.decayedClicks, decayedPurchases: r.decayedPurchases }));
// 4. arms + picks: Thompson slots then one widest-curve explore slot (Adcero's v1 recipe: 3 + 1)
const arms = armsFromBeliefs(beliefRows, 'angle_hook');
const exploit = thompsonPick(arms, 'click', makeRng(seed));  // or 'purchase' layer
const explore = widestCurvePick(arms, 'click');
```

**Caveats:**
- **A never-tried arm is invisible.** `armsFromBeliefs` iterates the rows you pass and never synthesizes a vague-prior arm. To explore your 12 pruned arms from day 0, add a zero-count row per arm (`buildCellBeliefs({…, decayedImpressions: 0, …}, table)` gives Beta(1,1)).
- **Excluded values:** `'other'` is dropped only as the exact value, so exclude `other|*` yourself.
- **Types:** `rollupPairs` types `dimension` as Adcero's closed `PerformanceDimension`. The runtime accepts `'angle_hook'`; widen the type in your copy (`loop/types.ts`), as `contracts-creative.ts` does.
- **Decay:** decay keys on `date` vs `asOf`. Give sim rewards sim-dates if you want forgetting.
- **Rejected alternatives:**
  - **Write `performance_memory` directly:** it needs DB rows, and the next `runCreativeLoopRollup` deletes them as stale.
  - **The arena:** `WorldPort.registerAd` sees only the cell, never ad text; `StubWriter` writes no copy; and the arena bans LLM-style non-determinism. So it can't host a text simulation without rewriting its operator/writer.
- **Prior art:** `tasks/creative-feedback-simulation-plan.md` (PLANNED, not started) describes "Layer 1" as exactly this pure seam, and states the non-negotiable that synthetic reward never touches production learning state.

## 11. Adcero defects found during this export (not fixed — the task is read-only)

1. **Self-repaired copy never reaches publish.** This is a compliance issue; it was verified by reading the code and was not run.
   - `pipeline-repair.ts:196` sets `candidate.copyText = repairCopy(...)`, which strips prohibited claims and avoid-words, and the gates re-pass on that text.
   - But the persisted `structured_copy` is built from the original `BrandCopyEntry` (`pipeline-stages.ts:877`), and Meta publish reads `structured_copy` (`app/api/creative-studio/candidates/[candidateId]/publish/meta-branch.ts:203`).
   - So a candidate whose prohibited claim was "repaired" can still publish with the claim. `generateBrandCopy`'s own guards don't check prohibited claims (only numerals and banned ad-speak).
2. **The text rank judge almost certainly always falls back to the heuristic.** This is probable; one live call would confirm it.
   - `CREATIVE_RANK_JUDGE_MODEL` defaults to `gpt-5.4-mini` (`model-roles.ts:104`).
   - `ranking.ts:170-175` sends it through `getLLMProvider().complete` with `temperature: 0` + `maxTokens`, which becomes Chat `max_tokens` (`lib/ai/provider.ts:54-55`).
   - `model-resolvers.ts:45-59` itself documents that gpt-5-class models reject that shape, and that the ranker "masks the identical failure with its heuristic fallback".
3. **Competitor `market_prior` facts enter the copy prompt as "Brand facts".** This is a behaviour question for you.
   - `ingest.ts:222` `NON_CONTEXT_SECTIONS` excludes only `performance_prior`, and `ingest.test.ts` asserts that `fact_market_prior_*` rows exist.
   - So "Winning competitor ads in this set use … in 7 of 12 …" can win one of the 3 fact slots. It then renders under `## Brand facts`, and its numbers become "grounded" for the numeral guard.
   - Whether market priors belong in copy at all is a product decision (themes code calls them "market-share prose"). Nothing was changed.
4. **The numeral grounding guard is a substring match.** Observed live in this export's first fixture run: a copy line citing an invented "**30**g" passed `findUngroundedNumerals` because "30" is a substring of "3,000" (normalized to "3000") in the grounding text (`brand-check/grounding.ts:23`). That candidate was removed from the shipped fixture. A token-boundary match would close it.
5. **Universal-angle themes rarely match the facts' industry-level themes.** Observed live.
   - A sampler or bandit choosing `angle_universal` (e.g. `health`) sets `spec.angleTheme = 'health'`, but `deriveFactThemes` tags protein facts `health_nutrition`.
   - `compile.ts:257` `matchesAngleTheme` is exact equality, so no fact gets the theme boost, and selection falls back to priority then rowId order.
   - In the fixture this dropped the brand's key "15g of plant protein" fact from the pack, so the real guard then **rejected** a copy line citing it.
   - Mitigation: pin the arm's strongest fact via `keyMessageRef`, or map universal → industry theme tokens before compiling.
